What's wrong

StratifiedCrossValidator.stratify_data hardcodes the label column name 'label' and ignores the estimator/evaluator's configured labelCol. If the dataset has no column named "label", dataset['label'] raises AnalysisException. The reporter's dataset has columns such as 'features' but no 'label'.
Show full explanationThe report's claim is confirmed: the column must be named 'label'. The README only documents 0/1 label values and never says the column must be called 'label'.
Model confidence: high.

How to reproduce

  1. Create a Spark DataFrame with a 'features' column and a binary target column named something other than 'label', e.g. 'target' with values 0/1.
  2. Build a StratifiedCrossValidator with any estimator (e.g. LogisticRegression(labelCol='target')), a paramGrid, an evaluator and numFolds=3.
  3. Call cv.fit(df).
  4. fit calls _fit, which calls stratify_data, which runs dataset['label'] and raises AnalysisException: Cannot resolve column name "label".
  5. Rename the column to 'label' and the error goes away.
