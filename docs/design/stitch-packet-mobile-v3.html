What's wrong

github.py labels each repo with project_type. The project-selection step drops the label, and transform.py never prints it, so the grader is told to score by a label it never sees.

Show full explanation

How to reproduce

  1. Run the pipeline on a profile with a GitHub repo that has several contributors.
  2. Print selected_projects in generate_projects_json: no project_type key.
  3. Print convert_github_data_to_text output: no Type line.
  4. Check the scoring evidence: projects treated as self_project.
